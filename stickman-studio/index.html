Each prompt asks for a grid of several scenes in a single image. Copy a prompt into ChatGPT or Gemini, download the image, and add it in the Grid Upload tab.

AI Scene Director (optional, best result)

Want a good visual description for every scene? Give this prompt to ChatGPT/Gemini, paste the reply below and press Apply. Each scene's "Visual" field gets filled in.

Upload grid images

The app finds the grid lines and cuts each panel into its own scene. If a cut looks wrong, turn off Auto-detect to split into equal parts, or increase Trim. If one panel is bad, upload a single image for just that scene.

Sync with the voiceover

Smart Sync finds the pauses and breaths in the voiceover and changes scenes there. For perfect timing use Tap Sync: listen and press Space at the start of each new scene. You can also drag the lines on the timeline to fine-tune.
